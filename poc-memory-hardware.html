The computer, as hardware - and what its RAM holds

Two views of the same program run, kept in step. On top, the physical board: the code travels out of the UFS storage chip, along the copper bus into RAM, into the SoC where a CPU core runs it. Below, a zoom into that RAM - the code, the globals, the stack and the heap that all share the one chip. Use Next / Play to step through it.

▼ zoom into the LPDDR5 RAM chip - one address space, opened up. Code, globals, stack and heap are all areas of this same chip.
LPDDR5 RAM address space 0x0000 → 0xFFFF
CODE · 0x0100 · the program's instructions
    GLOBAL · 0x1000 · values for the whole run
    STACK · 0x7000 · one frame per call · grows down ↓
    HEAP · 0x4000 · lives past the call · grows up ↑
