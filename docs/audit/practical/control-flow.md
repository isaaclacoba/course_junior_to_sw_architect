# Control Flow (`control-flow.js`)

- **Track / Part:** Practical - Part 1 Understand the ideas
- **Engine / format:** drill-engine (theory mode: quiz + fill-in-the-blank)
- **Difficulty pill:** Gentle  **XP cards (data-total):** 7
- **Runnable:** no (pure theory, no Run button)  **Theme:** neutral

## Concept(s) taught
The building blocks of control flow: `if`/`else`, boolean logic (`&&`, `||`,
`!`), `while`, `for`, `foreach`, `break`/`continue`, and `switch`. Each card
pairs a multiple-choice check with a fill-in-the-blank on the same idea.

## Card-by-card
| # | Card title | Concept | What the learner does |
|---|---|---|---|
| 1 | Branch with if / else | if / else | Fill `>=` and `else` in a pass/fail branch. |
| 2 | Combine conditions | Boolean logic | Fill `&&` and `!` to join comparisons. |
| 3+ | Loops / switch (while, for, foreach, break/continue, switch) | repetition & selection | Quiz + blank per construct. |

Each card carries: a `quiz` (one correct option with `answerWhy`), a display
`snippet` with `{{n}}` blanks, `points` (takeaways), and per-blank `hints` +
`explain` steps. Snippets are display-only (do not need to compile).

## Prerequisites
Assumes variables and types (Practice the Basics) and `bool`. Self-contained
otherwise; the concepts map onto the theory track's "Decisions and repetition".

## Complexity rung
Gentle, early. One control construct per card, small steps. Sits between
Practice the Basics and Methods - vocabulary the later build lessons rely on.

## Covered well
- Two-mode cards (recognise then produce) reinforce each idea.
- One construct per card; blanks target exactly the new token.
- Plain voice, accurate explanations, good `answerWhy` framing.
